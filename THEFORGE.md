# Publication sur The Forge

Une fois la release GitHub publiée, utilisez ce manifeste dans le Creator Dashboard de The Forge :

```text
https://raw.githubusercontent.com/Saurusius/hamecons-et-couronnes/main/module.json
```

Le champ `download` du manifeste pointe vers le ZIP de la release `v1.0.0`.

Pour tester avant soumission :

1. Ouvrez la page de configuration de Foundry VTT.
2. Choisissez **Add-on Modules** puis **Install Module**.
3. Collez l’URL du manifeste ci-dessus.
4. Vérifiez que Foundry télécharge et installe **Hameçons & Couronnes**.
