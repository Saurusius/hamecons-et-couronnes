# Publication sur The Forge

Utilisez ce manifeste stable dans le Creator Dashboard de The Forge :

```text
https://raw.githubusercontent.com/Saurusius/hamecons-et-couronnes/main/module.json
```

La version publique actuelle est **1.1.1 — La Vague des Trophées**.

Le champ `download` du manifeste pointe vers le ZIP de la release `v1.1.1`.

Pour tester avant soumission :

1. Ouvrez la page de configuration de Foundry VTT.
2. Choisissez **Add-on Modules** puis **Install Module**.
3. Collez l’URL du manifeste stable ci-dessus.
4. Vérifiez que Foundry télécharge et installe **Hameçons & Couronnes 1.1.1**.
